# Mission

Superpowers is a Claude Code plugin that provides a complete software development workflow for coding agents. It ensures agents follow disciplined processes — brainstorming designs before writing code, creating implementation plans, using TDD, performing code reviews, and managing git workflows — rather than jumping directly into implementation.

The core problem it solves: coding agents produce better results when they follow structured workflows (design, plan, implement, review) instead of ad-hoc code generation. Superpowers encodes these workflows as composable skills that activate automatically based on context.
