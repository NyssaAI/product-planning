# Codex installation

Install `plan-product` from the jamaynor marketplace. The native manifest loads the four skill bundles under `skills/`:

- `plan-product:plan-product`
- `plan-product:plan-feature`
- `plan-product:plan-use-case`
- `plan-product:plan-roadmap`

See [installation and usage](../README.md#codex-usage) for setup and the generated project structure.
