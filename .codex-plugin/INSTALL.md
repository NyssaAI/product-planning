# Codex installation

Install `plan-product` from the NyssaAI marketplace. The native `harness-adapter` manifest loads the `plan-product` skill under `skills/`:

- `plan-product:plan-product` (with workflows for product, concept, feature, use-case, development-plan, and maintain)

See [installation and usage](../README.md#codex-usage) for setup and the generated `repo_root` structure.
