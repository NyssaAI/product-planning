# F-01.01 Feature Catalog & Progress Tracking

## Summary

Maintain a single, user-readable catalog of all product capabilities showing how features are grouped and how much of each group is complete.

## User Need

Product owners and stakeholders need to scan the entire product's capabilities in plain, non-technical language, see which capabilities are planned versus complete, and jump to deeper feature details when needed.

## Use Cases

None yet.

## Scope

- Summarize completion progress across functional Feature Groups at the top of the catalog.
- Explain the numbering conventions so any reader understands how features, use cases, and roadmap steps relate.
- Provide a clean checklist summary listing only the status, feature ID, and plain feature title for quick scanning.
- Provide a detailed inventory section describing what each feature enables for users in non-technical language, along with a link to its feature guide.

## Out of Scope

- Technical build ordering and delivery phases (owned by F-03.01).
- Technical implementation details or technology selections.

## Inputs

- Approved feature definitions, functional groupings, and completion statuses.

## Outputs

- An up-to-date, user-friendly feature catalog with progress counts, a clean checklist summary, and plain-language feature descriptions.

## Acceptance

- The checklist summary contains only checkboxes, feature IDs, and titles—with no inline links or technical blurbs.
- Every feature in the catalog is described in non-technical, user-outcome language and links to its detailed guide.
- Completion counts in the summary table match the checked status of features in each group.

## Dependencies

- F-00.02, F-00.03.
