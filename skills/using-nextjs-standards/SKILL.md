# Using Next.js Standards

Follow **`../_shared/standards-discovery.md`** (Steps 1–3), including technology-specific precedence.

## Manifest filter

Entries whose `file` path starts with `standards/nextjs/`.

## Examples

A new marketing page pulls in `app-router.md`, `component-architecture.md`, `styling.md`, and `seo.md`.

## Cross-cutting

Standards in `standards/` without the `nextjs/` prefix apply to all code regardless of language. Consult `using-core-standards` for those.
