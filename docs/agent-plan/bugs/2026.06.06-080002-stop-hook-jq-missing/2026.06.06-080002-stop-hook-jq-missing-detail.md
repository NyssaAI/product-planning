# Bug: stop-hook-jq-missing

**Discovered:** 2026.06.06-080002

## Symptom

The dev-tools Stop hook fails when a Ralph loop state file exists in a Windows Git Bash environment without `jq`.

## Root cause

Confirmed: `hooks/stop-hook.sh` used `jq` to parse hook input, transcript JSONL, and final block output. The active Windows Git Bash runtime does not provide `jq`, so the hook exited with `jq: command not found` before it could honor session isolation or continue a Ralph loop.

## Contributing factors

The SessionStart hook already uses shell-only escaping, but the Stop hook still depended on an external JSON CLI that is not bundled with the plugin.
