# Feature Docs

Detailed plan-product feature guides live here.

Each feature maps to an ID in the `docs/features.md` inventory. Feature folders use lowercase IDs, for example `f-001/` or `f-201/`.

The main feature guide is always `feature.md` inside the feature folder. Specific use cases live beside it as `uc-001-short-slug.md`.

Use `.plan-product/templates/feature.md` as the starting shape for new feature guides.
Use `.plan-product/templates/use-case.md` as the starting shape for new use-case files.
