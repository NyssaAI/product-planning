# Bug: stale-local-ai-plan-scripts

**Discovered:** 2026.06.14-175825

## Symptom

Bootstrapped consumer repositories can keep `npm run ai-plan` and `npm run code-map` scripts that point at repo-local `scripts/ai-plan/generate.mjs` and `scripts/code-map/generate-code-map.mjs` copies. If those local copies are stale, regeneration can use old ai-plan/code-map behavior even after the installed dev-tools plugin has been upgraded.

## Root cause

The bootstrap script currently writes npm scripts that target repo-local vendored script paths instead of stable installed-plugin entrypoints.

## Contributing factors

- Current dev-tools `6.2.3` generator writes the new `docs/agent-plan/context/index.md`, `module-map.json`, and `modules/` layout, so the issue is not the current checkout's generator.
- Older consumer repositories may still have copied or vendored `scripts/ai-plan` and `scripts/code-map` tooling from earlier dev-tools versions.
- `scripts/ai-plan/lib/bootstrap.mjs` adds `package.json` scripts for `ai-plan` and `code-map` using repo-local `node scripts/...` commands when `--write-scripts` is used.
