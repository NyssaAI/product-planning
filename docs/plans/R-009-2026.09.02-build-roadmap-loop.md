# R-009 Roadmap Build Loop — Implementation Plan

Slice: R-009 — [F-401](../features/f-401/feature.md). A `build-roadmap` skill that implements roadmap slices in a Compound Engineering loop with dev-standards enforced throughout.

## Decisions

- The skill is a markdown workflow plus a reference file of subagent packets, matching every other plan-product skill; it ships no runtime script.
- The loop orchestrates existing host skills (`ce-plan`, `ce-doc-review`, `ce-work`, `ce-debug`, `ce-code-review`, `ce-compound`, `map-code`) and never reimplements their workflows.
- The roadmap is the work source when it exists; the feature inventory is the fallback. The skill never creates slices or a roadmap.
- `ce-plan` writes plans under its own naming; the loop renames the file to `structure.roadmap.planNamePattern` and links it from the slice so the roadmap contract holds.
- Review findings are applied by the orchestrator under the same bar `lfg` uses (concrete fix, high confidence, mechanical, evidence still matches); dev-standards findings that meet the bar are always applied.
- Shipping stays with the user: local commits only, never a push or PR.
