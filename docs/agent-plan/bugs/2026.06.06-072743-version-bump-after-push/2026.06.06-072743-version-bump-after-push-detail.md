# Bug: version-bump-after-push

**Discovered:** 2026.06.06-072743

## Symptom

The dev-tools plugin version bump happens after a GitHub push, so pushed plugin metadata can lag the intended release version.

## Root cause

Confirmed: dev-tools had a version bump script, but no active repository pre-push hook or hook installer that enforced version sync before publishing refs. The existing bump script also depended on `jq`, which was unavailable in the Windows Git Bash hook environment and would have made a pre-push check fail for the wrong reason.

## Contributing factors

The plugin repository had semantic version metadata in package/plugin manifests, plus mirrored `package-lock.json` version fields that were not declared in `.version-bump.json`.
