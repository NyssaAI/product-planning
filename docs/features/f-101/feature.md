# F-101 Feature Inventory

## Summary

Make `docs/features.md` the organized index for feature IDs, statuses, phases, and feature guide locations.

## User Need

An agent can quickly understand what must be built, in what order, and where the details live.

## Use Cases

None yet.

## Scope

- Explain feature ID naming.
- Explain feature file naming.
- Track delivery phases and progress.
- Link every feature to a detail file.

## Out of Scope

- Full product strategy replacement.
- Generated progress calculation.

## Inputs

- Feature list.
- Delivery phase model.

## Outputs

- `docs/features.md` inventory.

## Acceptance

- `docs/features.md` includes naming convention, file location rules, checklist summary, and phased inventory.
- Every linked feature guide exists.

- F-002.
