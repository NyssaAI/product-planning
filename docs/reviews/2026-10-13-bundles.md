## Help-probe incident and restoration

The baseline hook installer ignored `--help` and installed a real pre-push hook while validating documented CLI behavior. Its output said `installed`, which the inspected source emits only when the hook file did not exist; existing hooks instead emit `updated` or `appended to existing`. The new file contained solely the expected generated block targeting the review checkout. An exact whole-file comparison verified that content before native `Remove-Item -LiteralPath` removed the newly created file, restoring its prior absence. The parent was informed immediately. No existing hook content was removed. The runtime owner received this finding to implement safe help/argument handling. Future probes of scripts without a help handler were stopped.
